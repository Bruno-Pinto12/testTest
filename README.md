# PSM I Scrum Master question collection

This repository stores PDF files containing PSM I Scrum Master practice questions.

## Adding question files

- Add each PDF to the repository root.
- Use a descriptive filename, for example `psm-i-practice-questions-2026.pdf`.
- Keep the original wording and page layout so questions can be compared accurately.

## Comparing questions

When comparing PDFs, treat two questions as similar when they test the same Scrum concept, even if their wording, answer order, or scenario details differ. Record the source filename and page number for each matching question so duplicates can be reviewed before being removed.
