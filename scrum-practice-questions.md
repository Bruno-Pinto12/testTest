**Possible answers:**
- A. False
- B. True

**Correct answer:** B. True

**Exam explanation:** Scrum defines essential rules, not every implementation technique.

**Possible answers:**
- A. Continuously throughout the Sprint
- B. Only during Sprint Planning
- C. Only during the Sprint Review
- D. At the start of each Sprint

**Exam explanation:** Refinement is ongoing, as needed—not necessarily nonstop.
